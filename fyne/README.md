# Go Browser — Fyne

![Go](https://img.shields.io/badge/Go-1.25+-00ADD8?logo=go)
![Fyne](https://img.shields.io/badge/Fyne-2.8.1-9C27B0)
![Platform](https://img.shields.io/badge/platform-Linux%20%7C%20Ubuntu-orange)

Небольшой desktop-прототип браузера на Go, созданный с использованием **Fyne v2**.

Проект показывает, как на Go можно создать нативное графическое приложение с оконным интерфейсом, адресной строкой и кнопкой навигации.

На текущем этапе это прежде всего **учебный и экспериментальный проект**, предназначенный для изучения разработки desktop-приложений на Go.

---

## 📸 Интерфейс приложения

На первом этапе приложение содержит:

- главное окно;
- адресную строку;
- кнопку перехода;
- область для будущего отображения веб-страницы.

![Go Browser — Fyne](image/step1.png)

---

# 🎯 Что можно получить из проекта

Проект можно использовать как небольшой практический пример для изучения:

- разработки GUI-приложений на Go;
- библиотеки [Fyne](https://fyne.io/);
- создания окон и элементов интерфейса;
- работы с `Entry`, `Button`, `Label` и контейнерами Fyne;
- организации layout интерфейса;
- обработки действий пользователя;
- работы с Go-модулями;
- сборки desktop-приложений;
- использования CGO и системных графических библиотек Linux.

Главная идея проекта — показать путь от простого Go-приложения до desktop-интерфейса.
