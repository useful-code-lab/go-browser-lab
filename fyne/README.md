# Go Browser — Fyne

Учебная реализация desktop-интерфейса браузера на **Go** с использованием графического toolkit **Fyne v2**.

Проект показывает, как создать нативное desktop-приложение на Go без HTML/CSS-интерфейса: создать окно, адресную строку, кнопку навигации, обработать пользовательский ввод и организовать структуру GUI.

> На текущем этапе Fyne-версия является **GUI-прототипом**. Полноценный веб-движок в неё не встроен.

---

## 🎯 Что можно получить из проекта

Проект полезен как небольшой практический пример для изучения:

- создания desktop-приложений на Go;
- работы с Fyne v2;
- создания окон и элементов интерфейса;
- построения layout через контейнеры Fyne;
- обработки нажатий кнопок;
- обработки Enter в поле ввода;
- организации простого состояния приложения;
- работы с Go modules;
- сборки GUI-приложений с использованием CGO;
- подготовки Linux-приложения к запуску.

Проект особенно полезен как первый этап перед изучением более сложных desktop-технологий для Go.

---

## 🖥 Что реализовано

Текущая версия содержит:

- главное окно приложения;
- адресную строку;
- кнопку `Перейти`;
- обработку нажатия кнопки;
- обработку клавиши `Enter`;
- отображение текущего введённого адреса;
- статусную строку;
- базовую структуру desktop-интерфейса.
