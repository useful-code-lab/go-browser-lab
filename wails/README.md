# Go Browser — Wails

![Go Browser](image/wails.png)

**Go Browser** — отдельная реализация настольного браузера на **Go + Wails v3** с интерфейсом на **TypeScript**.


## Возможности

Текущая версия проекта предоставляет базовый интерфейс браузера и следующие функции:

- адресная строка;
- переход по URL;
- поиск через Google, если введён обычный поисковый запрос;
- автоматическое добавление `https://` для адресов без схемы;
- проверка URL и разрешение только `HTTP`/`HTTPS`;
- кнопка перезагрузки страницы;
- кнопка перехода на домашнюю страницу;
- быстрые ссылки на Google, GitHub и YouTube;
- индикатор загрузки;
- горячая клавиша `Ctrl + L` для выбора адресной строки;
- горячая клавиша `Ctrl + R` для перезагрузки страницы;
- `Escape` снимает фокус с адресной строки.

Кнопки **«Назад»** и **«Вперёд»** присутствуют в интерфейсе, но логика навигации по истории пока не реализована.
